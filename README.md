# PhD Stipend & Loan Budget Planner — public demo (Grad-IQ)

Live demo: https://saletra40-a11y.github.io/phd-stipend-loan-planner/

This is the **demo-only** edition. It runs on sample data, saves nothing, and has no export/import. The full planner (saves in your browser, JSON backup/restore, CSV export, print) is sold separately as a download.

Sections: 12-month stipend map with smoothed "pay yourself" amount · monthly budget (needs/wants/saving) · summer-gap cash check and buffer plan · student loan tracker with RAP due-date countdown, on-time window and on-time payment log · taxes & grad-money checklist.

Static HTML/CSS/vanilla JS. Self-hosted fonts. No tracking, no outside requests. Shop link and price live in `config.js` (`BUY_URL`, `PRICE`).

For planning only. Not financial, tax, or legal advice.

## Sources (checked Oct 16, 2026)
